## Kullanım

PHP dosyalarını çalıştırmak için bir web sunucusu (Apache, Nginx vb.) veya PHP'nin yerleşik sunucusunu kullanabilirsiniz:

```bash
php -S localhost:8000
```

Ardından tarayıcıda `http://localhost:8000/phpinfo.php` adresini ziyaret edebilirsiniz.
